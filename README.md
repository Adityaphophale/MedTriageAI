# MedTriageAI ⚕️

## Description 🏥

MedTriageAI is an AI-powered medical triage assistant designed to provide symptom-based guidance. It leverages Python, LangGraph, and Gemini AI to assist users in understanding their symptoms and potential next steps. This project aims to offer preliminary guidance and should not replace professional medical advice.

## Features ✨

*   **Symptom-Based Guidance:** Provides information and potential next steps based on user-provided symptoms.
*   **AI-Powered:** Utilizes LangGraph and Gemini AI for intelligent analysis and recommendations.
*   **Python Implementation:** Built using Python for flexibility and extensibility.
*   **Jupyter Notebook:** Implemented within a Jupyter Notebook for easy experimentation and demonstration.

## Tech Stack 💻

*   **Primary Language:** Python
*   **Frameworks:** LangGraph
*   **AI Models:** Gemini AI
*   **Environment:** Jupyter Notebook

## Installation 🛠️

1.  **Clone the repository:**

    ```bash
    git clone https://github.com/Adityaphophale/MedTriageAI.git
    cd MedTriageAI
    ```

2.  **Install the necessary Python libraries:**

    While the exact dependencies are not explicitly defined in a requirements file, based on the project description, you will likely need to install the following:

    ```bash
    pip install langgraph
    # Install other necessary libraries such as google-generativeai, etc.
    # Please refer to the MedTriage_AI.ipynb notebook for specific library imports
    ```

3.  **Open the Jupyter Notebook:**

    ```bash

    ```

## Usage 🚀

1.  **Open the `MedTriage_AI.ipynb` notebook in Jupyter.**
2.  **Follow the instructions within the notebook to input symptoms and receive guidance.**
3.  **Interact with the AI model to explore potential diagnoses and recommendations.**

**Example Use Case:**

Imagine a user experiencing a headache, fatigue, and a mild fever. They can input these symptoms into the MedTriageAI system, and the system will provide information about possible causes, suggest relevant questions to consider, and advise whether seeking professional medical attention is recommended.

**How to Use:**

*   Run the cells in the Jupyter Notebook sequentially.
*   Input the relevant symptoms when prompted.
*   Review the AI-generated guidance and recommendations.
*   Remember that this tool is for informational purposes only and should not replace professional medical advice.
